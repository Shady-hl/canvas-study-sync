# Canvas Study Sync

Open OPEN_RESYNC.command on Mac or OPEN_RESYNC.cmd on Windows from this tool folder. The normal window requires administrator-configured OAuth and explains missing setup without accepting pasted cookies/tokens. This remains a developer preview until an approved live integration is configured. Python 3.11+ is required.

Run setup once for manual extraction if needed. Keep course material, feed links and timing history private.

The source repository contains the full [usage guide](https://github.com/Shady-hl/canvas-study-sync/blob/main/docs/USAGE.md), [security policy](https://github.com/Shady-hl/canvas-study-sync/blob/main/SECURITY.md) and [noncommercial license](LICENSE.md).

Read the [OAuth setup and deployment limits](https://github.com/Shady-hl/canvas-study-sync/blob/main/docs/OAUTH_SETUP.md). Never distribute a developer-key client secret.
