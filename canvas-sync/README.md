# Canvas Study Sync

Open OPEN_RESYNC.command on Mac or OPEN_RESYNC.cmd on Windows from this tool folder. Choose Use downloaded files to build local study packs without a Canvas login, or Sync from Canvas with an approved, configured OAuth integration. The window explains missing sync setup without accepting pasted cookies/tokens. This remains a developer preview until an approved live integration is configured. Python 3.11+ is required.

PDF and timezone dependencies are prepared automatically when a build or sync needs them. Read the [student quickstart](https://github.com/Shady-hl/canvas-study-sync/blob/main/docs/QUICKSTART.md) for the complete Mac/Windows steps. Keep course material, feed links and timing history private.

The source repository contains the full [usage guide](https://github.com/Shady-hl/canvas-study-sync/blob/main/docs/USAGE.md), [security policy](https://github.com/Shady-hl/canvas-study-sync/blob/main/SECURITY.md) and [noncommercial license](LICENSE.md).

Read the [OAuth setup and deployment limits](https://github.com/Shady-hl/canvas-study-sync/blob/main/docs/OAUTH_SETUP.md). Never distribute a developer-key client secret.

Ed Discussion can be imported separately under Use downloaded files. Optional Remember on this computer uses the system secure store; saved tokens never enter portable copies. Read the [Ed setup guide](https://github.com/Shady-hl/canvas-study-sync/blob/main/docs/ED_DISCUSSION.md).
