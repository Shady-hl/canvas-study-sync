# Canvas Study Sync

Open OPEN_RESYNC.command on Mac or OPEN_RESYNC.cmd on Windows from this tool folder. Choose your Canvas HTTPS origin and an institution-approved credential in the local window. Python 3.11+ is required.

Run setup once for manual extraction if needed. Keep course material, feed links and timing history private.

The source repository contains the full [usage guide](https://github.com/Shady-hl/canvas-study-sync/blob/main/docs/USAGE.md), [security policy](https://github.com/Shady-hl/canvas-study-sync/blob/main/SECURITY.md) and [noncommercial license](LICENSE.md).
